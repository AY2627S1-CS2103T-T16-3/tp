# HR Book v1.3

HR Book adapts AddressBook Level 3 (AB3) for HR managers who maintain employee
records through keyboard commands.

## What's new compared to AB3

- **Employee records:** Manage employees with names, phone numbers, email
  addresses, addresses, and tags using the familiar add, edit, list, find,
  and delete commands.
- **Salary tracking:** Supply an optional salary when adding an employee, for
  example `add n/Alice Tan p/91234567 e/alice@example.com a/123 Clementi Road
  s/5000 t/engineering` (enter this as one line). Salary defaults to `0`, accepts
  whole numbers from `0` to `50000`, and appears with a `$` prefix on employee
  cards. Leading zeros are normalized.
- **Dedicated salary updates:** Use `salary 1 s/5500` to update the salary of
  the first employee in the displayed list. Other employee details are
  preserved, and a successful update displays all employees. Use this command
  rather than `edit` to change salary.
- **Search across multiple fields:** Use `filter` to search names, phone
  numbers, email addresses, addresses, and tags. For example,
  `filter n/Alice t/engineering` finds employees matching both criteria.
  Text fields use case-insensitive substring matching; tags use
  case-insensitive whole-tag matching. Multiple tag criteria require every
  specified tag. Each filter searches all stored employees; `list` restores
  the full list.
- **Workforce summaries:** Run `/summary` or `summary` to see the total number
  of employees, the number without tags, and employee counts for each tag.
  Summaries include the entire stored workforce even after filtering, group
  tags without regard to case, and list tag groups alphabetically. Employees
  with multiple tags contribute to each group.
- **Salary persistence:** Employee salaries are saved with the employee data.
  Older records without a salary load with a salary of `0`.

## Running HR Book

Install Java 25, download the attached `addressbook.jar` into a dedicated
folder, and run:

```text
java -jar addressbook.jar
```

Employee data is saved automatically. Back up existing data before upgrading.

## Scope

This release retains AB3's command-driven interface and local saving. Leave
management and task-management commands are not included in this release.
